# 写作星河 · UI 设计文档

> 面向网文作者的一键大纲 + 3D 人物/势力关系图写作工具。
> 本设计定位：**IDE 系（VSCode / Trae 风格）视觉语言 + 双主题（亮/暗）+ 弱人机感**。
> 配套原型见 `ui/prototype/index.html`（静态、可点、可切换主题）。

---

## 1. 设计定位与原则

### 1.1 为什么选 IDE 设计语言

方案 1.2 的四栏 + tab 工作区布局，结构上与代码编辑器（VSCode/Trae）天然同构：

| 写作星河 | 对应 IDE 概念 |
| --- | --- |
| 左侧「作品/分类」栏 | Activity Bar（活动栏） |
| AI 交互栏 | 侧边栏（Panel） |
| 中间 tab 工作区 | Editor / Editor Tabs |
| 右侧内容树 | Explorer（资源管理器）|
| 底部时间轴 scrubber | Status Bar 区域的辅助面板 |

因此直接采用 VSCode/Trae 的设计语言，**零学习成本**、创作者驾驭感强，同时用「文学质感 + 弱人机感」做差异化润色，避免生硬的"软件脸"。

### 1.2 弱人机感（De-robotized）的具体手段

> "人机感太重"通常来自：纯黑底、荧光高亮、机械直角、生硬弹窗、过多表单。逐条抹平：

1. **去掉生硬弹窗**：新建/确认类操作优先用「行内输入」「下划线编辑」「抽屉」替代阻塞式 Modal；确需 Modal 时用柔和圆角（10px）+ 微遮罩 + 缩放渐变动画。
2. **温暖配色**：暗色不是纯黑，而是偏蓝灰的柔黑夜（`#17191f` 级别）；强调色用低饱和青绿而非荧光绿/蓝。
3. **圆角与留白**：控件 6–8px 圆角、tab 标题留呼吸、行高 1.6。图标线条化、尖角柔和。
4. **文案人性化**：按钮/空态/提示用"写作语言"而非"系统语言"：
   - 空章节 → "这一章还没有落笔，点这里开始"
   - 无关系 → "人物们还没相遇，先从登场关系画起"
   - 确认关系 → "确认这条关系" 而非 "OK"
5. **克制动效**：hover 变亮、淡入淡出、tab 平滑切换、关系渐入渐出；禁用弹跳/抖动。
6. **状态可视化**：草稿/完成/待确认用柔和角标和低饱和色点，而非刺眼徽章。

### 1.3 整体审美关键词

安静 · 纸张感 · 深空 · 克制的强调色 · 编辑器般的精度
- 背景如"翻开的纸页 / 夜色下的稿纸"，前景如"墨水与星光"。
- 强调色贯穿"写作功能"（编辑、大纲、关系图、AI 栏），不喧宾夺主。

## 2. 色彩系统（Design Tokens）

> 采用 CSS Custom Properties + 亮/暗双主题。装饰色定为 **青绿（teal/emerald）**：
> 呼应"写作星河"的星海意象，又区别于 VSCode 默认科技的蓝、Trae 的蓝，形成品牌识别；对关系图色板（红/金/粉/橙等语义色）不冲突。

### 2.4 3D 关系图语义色板（数据结构驱动，见方案 4.2.6）

| 关系类型 | 边色 | 方向 |
| --- | --- | --- |
| belong_to 从属 | `#8d9199` 灰 | 有向 |
| ally 结盟 | `#3dbd7d` 绿 | 无向 |
| enemy 敌对 | `#e5484d` 红 | 无向 |
| kinship 亲属 | `#d9b64c` 金 | 无向 |
| master_disciple 师徒 | `#4f9df0` 蓝 | 有向 |

- **节点底色**：人物用强调青绿系渐变，势力用深空靛蓝；可在暗色主题下自动提亮，保证 3D 上可辨识。
- **大小映射**：`size = 5 + importance * 25`（方案 4.3）。
- 势力聚簇用同 `factionId` 的近似色 + 聚类力（方案 4.3）。

## 4. 组件与交互设计

### 4.1 活动栏（Activity Bar，最左）
- 图标竖向排列：**作品列表（库）、AI、设置**，底部放「主题切换」+「用户/作者头像」。
- 选中项左侧会有 2px 青绿指示条，悬停显示 tooltip。
- 图标用描边风格（1.5px 线条），hover 描边变强调色。

### 4.2 作品列表（点活动栏「库」展开的最近面板 / 或作最左窄栏内容）
> 提供两种呈现，MVP 取 A：
> - **A（推荐）**：活动栏点「库」→ 弹出作品抽屉/面板，列出最近作品 + 「新建作品」行内输入。
> - B：永久左栏。空间紧，不推荐。
- 每项显示：作品名、字数、最后编辑时间。
- 「新建」：行内文件名式输入（青色下划线聚焦），回车即建，去 Modal。

### 4.3 AI 交互栏（Trae/Panel 侧栏）
- 顶部：图标 + 「AI 助手」标题 + 模型下拉（GLM-4 · DeepSeek V4 · 通义…）。
- 中部快捷操作卡片（**写作场景直达**）：一键大纲 / 分析本章 / 批量分析 / 续写 / 问答。
- 底部：输入框 + 常用模型快捷标签；发送按钮为青绿圆钮。
- AI 回复气泡：柔和圆角、左对齐；代码/大纲等结构化内容用衬底灰块；「接受 / 进入草稿」按钮温和呈现。
- **弱人机感**：占位文案为「问问我，或试试下面的快捷入口」。

### 4.4 内容树（Explorer）
- 分目录：章节 / 大纲 / 人物关系图 / 设定集，用 macOS 式文件夹折叠箭头。
- 章节项：显示「第 N 章 · 标题」，尾部状态点（灰草稿 / 绿完成 / 琥珀待确认）。
- 动态操作用 hover 露出小图标（新建章、插入章、删除）。
- 待确认实体（`confirmed=false`）：标题旁琥珀色小点 + "待确认"细字，点击进抽屉修正（对应方案「前端标红人工确认」）。

### 4.5 Tab 工作区
- Tab 形态：圆角小胶囊，激活项底部斜切连接正文（VSCode 式）；可拖拽排序。
- 每 Tab 图标区分类型：章=文书、大纲=树、关系图=星网、设定=齿轮。
- 关闭按钮 hover 显现；右键菜单：关闭其他 / 关闭所有 / 固定。
- 切换动画：工作区内容 140ms 淡入 + 4px 上移。

### 4.6 编辑器（CodeMirror 6）
- 单行高 20px、行号灰、当前行 5% 强调浅底。
- 字号 15px；衬线字体可选（中文「宋体/Source Han Serif」开关）提升"写作感"。
- 顶部面包屑：`作品 / 第 N 章`；右侧字数统计 + 保存状态（"已保存 HH:mm" / "保存中…"）。
- 底部状态条并入全局状态栏。

### 4.7 大纲视图（打开「大纲」Tab）
- 树状三层（总纲 → 分卷纲 → 章纲），可折叠、拖拽同级排序。
- 章纲节点右侧「跳转章节」小图标 → 打开对应该 `sort_order` 的章节 Tab。
- 节点行尾部：小节字数 / 是否已关联章节（未关联章纲显示"待关联"细字）。

### 4.8 3D 关系图视图（硬需求，对应方案 5.3）
- 打开即工作区进入全屏视图（保留顶部 tab 条 + 底部 scrubber）。
- **顶部浮动工具栏**（半透明胶囊）：模式切换（上帝视角/时间轴）、势力过滤、重要性阈值滑块、2D/3D 投影开关、重新布局。
- **底部 scrubber**：时间轴，轴上按 `sort_order` 布点（标出章节位置），拖动改变 `currentSort`，节点/边随坐标渐入渐出。当前章节以青绿刻度高亮。
- 节点 hover：高亮与其相连的边 + tooltip（名称 / 势力 / 重要性）。
- 节点点击：右侧滑出**档案抽屉**（人物/势力档案 + 出场章节列表 + 关系列表），符合方案 4.3。
- 时间轴模式下，未出场节点以 20% 透明"幽灵态"呈现或隐藏（可切换），已死亡/退场节点用描边虚线表示。
- 2D/3D 开关为降级保障（方案 7 M2）。

### 4.9 抽屉（Archive Drawer）
- 从右侧滑入，宽度 360px，遮罩可点。
- 分段：基本信息 / 出场时间轴 / 关系网络 / 「确认后转正」（`confirmed` 操作）。
- 字段用一下划线编辑样式，符合"手写修正"感。
- 关闭动画：右滑 + 淡出 180ms。

### 4.10 状态栏（底部）
- 左：当前文件只读/可写、语言/字体（如「宋体 · 15px」）。
- 右：字数、坐标（`sort_order`）、AI 状态（分析中…/就绪）、主题切换快捷键。
- 最低反光底色，几乎所有文字为 `--fg-muted`，弱化存在感。

### 4.11 弹层与 Menu
- 使用柔和阴影 + 10px 圆角 + 150ms 缩放入场（scale .98→1）。
- 菜单项 hover 用 `--bg-hover`。
- 唯一 Do：提示、确认有破坏性操作才用 Modal（如"删除本章"，二次确认文案人性化）。

## 5. 交互状态规范

| 状态 | 表现 |
| --- | --- |
| 默认 | 常规色 + `--border` |
| hover | `--bg-hover` 淡入，140ms |
| 激活/选中 | `--bg-active` + 左/下 2px 青绿指示 |
| 禁用 | `--fg-faint`，不可点 |
| 焦点 | 2px `--accent` 圆角描边环（非 auto 浏览器环）|
| 待确认（数据）| 琥珀色小点 + 细字标签 |
| 拖拽中 | 半透明投影 + 原位移位 |
| 保存中 | 状态栏"保存中…"转圈 900ms |

规则：**所有色彩/状态切换统一 140ms ease**；动效克制，无弹跳；右键菜单用轻动画。

## 6. 字体排版

- 界面 UI：`system-ui, -apple-system, "Segoe UI", "PingFang SC", "Microsoft YaHei"`；UI 字号 12–14px，正文/代码编辑 15px。
- 编辑器可选**衬线写作模式**：`"Source Han Serif SC", "Songti SC", SimSun, serif`（提升文学感，属可开关选项）。
- 行高：正文编辑 1.7，面板 1.5。
- 等宽用于数字/坐标/时间：`SF Mono, Consolas, "JetBrains Mono"`。

## 8. 原型说明

- **纯静态**、无依赖、直接双击打开。
- 右上角 / 活动栏底部可切换 **亮 / 暗** 主题（持久化到 localStorage）。
